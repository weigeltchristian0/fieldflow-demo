# QA

This directory stands in for a QA wiki. Everything here is markdown, committed
alongside the code it describes.

| Path | Written by |
|---|---|
| `ticket-qa/<issue>/cases.md` | qa-test-cases |
| `ticket-qa/<issue>/code-review-<date>.md` | qa-code-review |
| `ticket-qa/<issue>/run-<date>.md` | qa-execute |
| `library/<area>.md` | qa-test-cases, merged by ID |

Review and run pages are dated, so history accumulates rather than being
overwritten. The library is merged by ID, so canonical cases are never
duplicated.
